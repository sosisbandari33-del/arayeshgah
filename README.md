# سامانه نوبت‌دهی آنلاین «پیرایش کلاسیک»

سامانه مستقل نوبت‌دهی آرایشگاه، طراحی‌شده جهت رزرو نوبت بدون نیاز به حساب کاربری برای مشتریان و مشاهده و مدیریت نوبت‌های روزانه برای صاحب آرایشگاه.

---

## وضعیت فعلی پروژه

* **فرانت‌اند:** React (Vite) با پشتیبانی کامل از چینش راست‌چین (RTL)، فونت استاندارد وزیرمتن، پالت رنگی یکدست و طراحی واکنش‌گرا روی موبایل، تبلت و دسکتاپ.
* **بک‌اند:** FastAPI (Python) همراه با اعتبارسنجی ورودی‌ها، نرمال‌سازی ارقام فارسی و عربی، کنترل دقیق قوانین کسب‌وکار و تنظیمات CORS.
* **دیتابیس:** SQLite (`backend/barbershop.db`) شامل جداول خدمات (`services`) و نوبت‌ها (`appointments`).

### مرحله دوم: راه‌اندازی بک‌اند (Python FastAPI)

در ترمینال اول، دستورات زیر را برای ساخت محیط مجازی، نصب وابستگی‌ها و اجرای سرور اجرا کنید:

#### در ویندوز (PowerShell / CMD):
```powershell
# ۱. ورود به پوشه بک‌اند
cd backend

# ۲. ساخت محیط مجازی پایتون
python -m venv venv

# ۳. فعال‌سازی محیط مجازی
.\venv\Scripts\activate

# ۴. نصب کتابخانه‌ها و وابستگی‌ها
pip install -r requirements.txt

# ۵. اجرای سرور توسعه با uvicorn
uvicorn main:app --reload
```

#### در لینوکس یا مک (Linux / macOS):
```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

* **آدرس سرور بک‌اند:** `http://127.0.0.1:8000`
* **مستندات تعاملی Swagger:** `http://127.0.0.1:8000/docs`

### مرحله سوم: راه‌اندازی فرانت‌اند (React Vite)

## مستندات اندپوینت‌های API

| متد | آدرس اندپوینت | شرح عملکرد |
| :---: | :--- | :--- |
| `GET` | `/api/services` | برگرداندن لیست کلیه خدمات و تعرفه‌ها |
| `GET` | `/api/slots?date=YYYY-MM-DD` | دریافت بازه‌های ۳۰ دقیقه‌ای و وضعیت پر/آزاد بودن در تاریخ انتخابی |
| `POST` | `/api/appointments` | ثبت نوبت جدید با اعتبارسنجی قوانین R1 تا R3 و ارقام فارسی |
| `GET` | `/api/appointments?date=YYYY-MM-DD` | دریافت نوبت‌های یک روز مشخص مرتب‌شده بر اساس ساعت شروع |
| `PATCH` | `/api/appointments/{id}/cancel` | لغو نوبت و آزادسازی بازه زمانی طبق قانون R4 |
| `GET` | `/api/test` | تست سلامت سرویس بک‌اند |

## قوانین کسب‌وکار فعال (Business Rules)

1. **قانون R1:** ساعات کاری روزانه ۱۰:۰۰ الی ۲۰:۰۰ در قالب بازه‌های ۳۰ دقیقه‌ای است.
2. **قانون R2:** هر بازه تنها پذیرای یک نوبت است و از رزرو تکراری یا تداخل با پیام خطای مشخص جلوگیری می‌شود.
3. **قانون R3:** ثبت نوبت برای تاریخ‌ها و ساعت‌های گذشته امکان‌پذیر نیست.
4. **قانون R4:** لغو نوبت رکورد را پاک نمی‌کند؛ وضعیت رکورد به «لغو شده» تغییر یافته و ساعت آن مجدداً برای رزرو آزاد می‌گردد.
