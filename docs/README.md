## پنج اصل نگهداری مستندات
1. **فقط وضعیت الان:** FRDها و سند معماری تنها رفتار و ساختار فعلی و فعال پروژه را شرح می‌دهند (اهداف سطح ۲ فقط در PRD تفکیک شده‌اند).
2. **هر واقعیت فقط در یک جا:** از تکرار محتوای یک سند در سند دیگر خودداری کنید و به منبع اصلی لینک بدهید.
3. **بدون کپی کد در داک:** جزئیات پیاده‌سازی، کوئری‌ها و منطق کد را مستقیماً از فایل‌های منبع بخوانید.
4. **همگام با کد:** در قدم ۵ هر تسک، سند مربوطه در همان تغییر به‌روزرسانی شود.
5. **کوتاه و دقیق:** مستندات باید مختصر، شفاف و قابل‌استفاده‌ی سریع برای انسان و ایجنت باشند.
